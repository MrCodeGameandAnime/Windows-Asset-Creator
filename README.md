# Windows Asset Creator

Windows Asset Creator (WAC) is a native Windows utility from **404 Builds** that turns one PNG or JPEG into a validated set of Microsoft Store/MSIX image assets.

**[Get Windows Asset Creator from the Microsoft Store](https://apps.microsoft.com/detail/9ppcx5fvpdn3?hl=en-US&gl=US)**

WAC previews and exports 70 PNG assets plus `AppIcon.ico` in a ZIP. Image processing happens locally, and non-square artwork is centered without cropping.

See the [project overview, screenshots, build instructions, and tests](docs/README.md).
